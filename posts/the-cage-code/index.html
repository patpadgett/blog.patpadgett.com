The CAGE code. Five characters, folks.

VimOps became a registered federal vendor with CAGE code 8PMQ9. That identifies the business, folks. It does not mean the government reviewed my software.

Those five characters next to VimOps on my resume, 8PMQ9, are our CAGE code[1]Ref. 1CAGE code cage.dla.mil. It fits the history of becoming a registered federal vendor[2]Ref. 2registered federal vendor sam.gov into considerably less space than this explanation is going to take.

It identifies an entity. A contracting officer still has to decide whether I'm the best person for a job, and I still need a proposal with a reasonable price and proof I've met a particular requirement.

I'm not claiming VimOps's registration is active on whatever day you're reading this. My resume establishes the registered-vendor history and CAGE code. Current status requires a current lookup. I'd want that lookup for anybody waving a vendor number around in a proposal, too.

I can pick a really good font and make the code bigger, but somebody is still going to ask for those answers. I'd better have them ready.
